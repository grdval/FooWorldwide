# FooWorldwide

A Vite + React website project for FooWorldwide.

## Features
- Responsive React layout
- Animated GIF and media-based member cards
- Audio playback for selected profiles
- Vite development and build workflow

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Production build

```bash
npm run build
```

## Notes
- This project includes media assets under `src/assets`.
- Do not commit private credentials, API keys, or secrets.
